MIMO: My Little World - Stage 1 (5 rooms)

HOW TO RUN
1. Unzip the folder.
2. Double-click index.html (opens in Chrome, Edge, Firefox or Safari).
   No login or install needed.

REQUIRES INTERNET: Three.js (r128) is loaded from cdnjs.cloudflare.com.
To run fully offline, download
https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
into this folder and change the <script src=...> line in index.html to "three.min.js".

CONTROLS
WASD / arrow keys (Shift = run), or click the floor to move.
Click objects: bookshelf, desk, wardrobe, MIMO the cat, fridge, stove, TV, sofa, shower, mirror, balcony plants and chair.
Room menu is on the left. Esc closes a panel.

SAVING: progress is stored in your browser (localStorage). It does not sync across devices or browsers.

DONE: 5 rooms, cel-shaded 3D look, click-to-move + pathfinding, companion cat that follows,
subjects, real focus timer with rewards, wardrobe (hoodie/hair colour + 3 hairstyles),
cooking + food inventory, memory-match mini-game, plant watering, room-visit reward.

NOT DONE: 20 character presets, tasks, notes, calendar, shop, decoration placement,
photo mode, walking through doorways, 6th room, real 3D models/painted art.
This build has not been tested by the author in a live browser.
